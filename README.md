# Tab5 Flight Tracker

M5Stack Tab5で羽田・関西・那覇・新千歳の空を眺める、タッチ操作のフライトレーダーです。空港周辺の海岸線と、日本時間を表示するフリップ時計を内蔵しています。

## 初回設定

1. Tab5をUSB接続し、PC版ChromeまたはEdgeで [web/settings.html](web/settings.html) を開きます。
2. 「USBで接続」でTab5のシリアルポートを選びます。シリアルモニターは先に閉じてください。
3. 2.4 GHz Wi-FiのSSIDとパスワードを入力し、「Wi-Fiを保存して接続」を押します。次回のUSB接続時は、本体のNVSに保存したSSIDが入力欄に表示されます。パスワード欄は空欄です。
4. 接続すると設定ページとTab5にIPアドレスが表示されます。同じLANのブラウザーでそのアドレスを開くと、表示設定を変更できます。
5. 登録後は「USBを切断」でポートを解放できます。Windowsで接続するときは、ページ側がRTSを先に解除してからDTRを設定します。

USB・LANの設定画面で「表示地域」を選び、「表示設定を保存」を押すと、地図とライブデータが切り替わります。初期値は羽田です。

地域、明るさ（5〜100%）、半径（10・20・40・60海里）、注目機の切替間隔（5〜60秒、0で停止）、レーダーの回転周期（3〜20秒）は再起動後も保持します。Wi-Fi接続先の変更はUSBから行います。LAN設定は同じネットワークから利用できるHTTP接続です。APIキーはUSBからも登録でき、設定画面には登録状態だけを返します。

## 画面の操作

- 地域名をタップすると羽田→関西→那覇→新千歳、レーダー左下の縮尺をタップすると10→20→40→60海里の順に一周します。本体での切替は一時的で、再起動するとUSB・LAN設定で保存した値に戻ります。
- 横向きのまま本体の上下を逆にすると、表示とタッチ座標が180度回転します。平置きや浅い傾きでは直前の向きを保持し、上下方向に約35度以上傾いた状態が3回続くと切り替わります。
- 地図の機影または右の一覧をタップすると、その機体を固定します。機体の詳細カードをタップすると自動切替に戻ります。
- 「Nearby aircraft」の「Moving / 30+ kt」をタップすると、対地速度30ノット以上と全機を切り替えます。速度不明の機体は全機表示に含まれます。「<」「>」で3機ずつ前後のページに移動します。地図は両方の表示で全機を対象にします。
- 受信の合間は、最後の対地速度と航跡角で機影の位置を予測します。速度や方向が不明なら観測位置を保ち、取得が遅れたときは次の更新予定時刻で予測を止めます。航跡の点は受信位置です。
- 初回のWi-Fi未設定時は架空の機体によるデモで起動し、接続するとライブ表示に切り替わります。
- 左の地図は北が上です。右にコールサイン、機種コード、高度（ft）、対地速度（kt）、対地航跡角（度）、選択した空港からの距離（NM）を表示します。

## ライブデータ

[adsb.lol](https://www.adsb.lol/docs/open-data/api/) の公開APIから、選択した空港を中心に半径60海里の位置を180秒おきに取得します。同じ地域を24時間表示した場合は約480回です。公開枠は同じ送信元IPで1日500回のため、HTTP 429ではサーバー指定の待ち時間を優先します。データのライセンスは [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/) です。

設定ページの「航空データ」に自分のadsb.lol APIキーを登録すると、取得間隔を10〜86400秒の範囲で1秒単位で指定できます。本体がデータを正常に受信した時点で指定間隔に切り替えます。未登録または認証エラー（401・403）なら公開枠の180秒に戻ります。10秒間隔で終日動かすと8,640回なので、キーの利用枠に合わせて設定してください。「キーを削除」で公開枠に戻せます。

最大96機を近い順に保持します。ADS-B分類が地上車両・障害物（C1〜C5）の送信元を除外します。TLS証明書検証のため、初回はNTP時刻同期を待ちます。

陸域は [Natural Earth 1:10m Land](https://www.naturalearthdata.com/downloads/10m-physical-vectors/10m-land/)（パブリックドメイン）を使用しています。地図を再生成する場合は `python tools/make_coast.py ne_10m_land.geojson` を実行します。

## ビルド・書き込み

対象はESP32-P4 rev.1.0のM5Stack Tab5です。USBを接続し、PlatformIOで実行します。

```sh
pio run -e tab5
pio run -e tab5 -t upload
```

複数の機器がある場合は `pio device list` でTab5を確認し、`--upload-port` で指定してください。設定ページ、イラスト、地図はファームウェアに含まれます。

### LANからのファーム更新

1. LAN更新に対応したファームを初回だけUSBで書き込みます。PCまたはスマートフォンをTab5と同じLANに接続し、本体に表示されたIPアドレスを開きます。USB設定ページからも「LAN設定・ファーム更新を開く」で移動できます。
2. 「ファームウェア更新」でTab5 Flight TrackerのBINを選びます。PlatformIOの `.pio/build/tab5/firmware.bin` と、このプロジェクトのUSB用結合BIN（アプリは0x10000）が使えます。
3. 本体の「OTA code」をタップするか、USB設定ページで「更新コードを発行」を押します。LAN画面に6桁のコードを入力し、2分以内に「ファームを書き込む」を押してください。
4. 完了するとTab5が再起動します。別のアプリ領域に書き込むため、Wi-Fi・APIキー・表示設定を引き継ぎます。

## 設定ページの公開

リポジトリの **Settings → Pages → Source** で **GitHub Actions** を選択します。**Actions → 設定ページを公開 → Run workflow** で公開すると、[USB設定ページ](https://ropo.github.io/Tab5FlightTracker/) を開けます。`master` の設定ページやイラストを更新すると自動で再公開します。
